# COM-112: Auto-Refund Parameterization for Late Fees Triggered by System Glitches

<a id="COM-112-D01"></a>
## 1. Defining Glitch-Induced Late Fees
If a customer attempts a loan repayment via Paygate, but the system times out and delays the settlement past the due date, any resulting late fees generated by the core system are classified as glitch-induced.

<a id="COM-112-D02"></a>
## 2. Auto-Refund Execution
Ngân hàng Mô phỏng utilizes an Auto-Refund daemon. If a late fee (Code: LATE_FEE_55) correlates with a logged Paygate timeout event for the same customer within a 48-hour window, the daemon automatically posts a fee reversal to the customer's account without requiring manual ticket escalation.
