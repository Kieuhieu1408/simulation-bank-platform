# COM-107: Synchronous vs Asynchronous Paygate Fallback Modes

<a id="COM-107-D01"></a>
## 1. Mode Switching Parameters
During high load or partial degradation, Ngân hàng Mô phỏng's Paygate gateway will automatically toggle from synchronous API processing to asynchronous message queuing (AMQP). This transition occurs when CPU utilization across API gateways exceeds 85% for 3 consecutive minutes.

<a id="COM-107-D02"></a>
## 2. Customer Notification Rules
When asynchronous mode is active, customer receipts must dynamically render the disclaimer: "Giao dịch đang được xử lý chậm do hệ thống quá tải" (Transaction is processing slowly due to system overload). Standard SLAs for execution are temporarily suspended.
