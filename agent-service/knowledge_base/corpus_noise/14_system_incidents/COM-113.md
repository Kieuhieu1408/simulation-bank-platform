# COM-113: Interest Calculation Overrides for Delayed Holiday Settlements

<a id="COM-113-D01"></a>
## 1. Holiday Accrual Misalignments
In scenarios where a multi-day holiday delays settlement of large commercial deposits, the standard interest accrual script may undercalculate yield. Ngân hàng Mô phỏng requires treasury to monitor these misalignments specifically for tier-1 corporate clients.

<a id="COM-113-D02"></a>
## 2. Manual Yield Adjustment
A manual override is applied to the interest engine using the `YIELD_ADJ_HOLIDAY` parameter. This instructs the core system to back-date the principal deposit value to the original initiation date, ensuring the client receives full interest accrual across the non-working days.
