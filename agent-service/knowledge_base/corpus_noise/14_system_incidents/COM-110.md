# COM-110: Fraud Screening Bypass Protocols During High-Volume Paygate Outages

<a id="COM-110-D01"></a>
## 1. Systemic Risk Triage
If the AML/Fraud screening API integrated with Paygate experiences an outage, Ngân hàng Mô phỏng enters a Systemic Risk Triage state. Transactions under the micro-payment threshold (under 2,000,000 VND) are permitted to bypass real-time screening.

<a id="COM-110-D02"></a>
## 2. Post-Factum Analytics
All bypassed transactions are tagged with `BYPASS_AML_GLITCH`. Once the screening API is restored, a post-factum batch analysis is executed. Any flagged transactions from the bypass window generate immediate alerts to the Compliance Department for retroactive manual review.
