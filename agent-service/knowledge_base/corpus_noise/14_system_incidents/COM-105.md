# COM-105: Inter-Branch Transfer Isolation During Partial Core Network Partition

<a id="COM-105-D01"></a>
## 1. Network Partition Detection
A partial core network partition is defined when branch local servers cannot communicate with the central Ngân hàng Mô phỏng datacenter but retain external ISP access. Paygate terminals at affected branches will fail over to 4G cellular backup routing.

<a id="COM-105-D02"></a>
## 2. Transfer Isolation
During a partition, inter-branch transfers are strictly isolated to a store-and-forward queue. No direct settlement is permitted. Manual overrides are disabled to prevent double-spending risks until the partition is fully resolved.
