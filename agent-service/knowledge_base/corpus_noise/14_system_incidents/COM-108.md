# COM-108: Paygate Connection Glitches with Central Bank Clearing (CITAD)

<a id="COM-108-D01"></a>
## 1. CITAD Gateway Disconnects
A Paygate connection glitch specific to the CITAD (Central Bank Inter-bank Payment System) gateway requires immediate escalation to the Ngân hàng Mô phỏng Treasury Desk. Outgoing CITAD transfers above 500M VND are held in suspense.

<a id="COM-108-D02"></a>
## 2. Recovery and Value Date Adjustment
Upon restoring the CITAD connection, backlogged messages are transmitted with the original Value Date. If the glitch spans across the 16:30 cutoff, the Value Date must be manually overridden to T+1 to avoid central bank penalty fees.
