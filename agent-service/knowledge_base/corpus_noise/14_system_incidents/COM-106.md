# COM-106: Paygate Timeout Resolution and Orphaned Transaction Sweeps

<a id="COM-106-D01"></a>
## 1. Timeout Thresholds
If a payment instruction sent to the central Paygate bus does not receive an acknowledgment within 15 seconds, a timeout exception is generated. Ngân hàng Mô phỏng sets these transactions to a `PENDING_ORPHAN` status to await the hourly sweep.

<a id="COM-106-D02"></a>
## 2. Orphan Sweep Protocol
The hourly `SWP_ORPHAN_CRON` job queries the central switch for final statuses. If the transaction was successful at the beneficiary bank but failed to update locally, the system applies a forced GL entry to harmonize the accounts.
