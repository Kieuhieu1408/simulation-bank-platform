# COM-101: Core Banking Planned Maintenance Override Protocols

<a id="COM-101-D01"></a>
## 1. Maintenance Windows and GL Freezes
During planned downtime of the Ngân hàng Mô phỏng core banking system, all automated General Ledger (GL) posting threads are frozen. The Paygate system will enter a read-only state for balance inquiries, returning cached data with a 15-minute TTL.

<a id="COM-101-D02"></a>
## 2. Manual Override Ledger Initialization
For emergency high-value transactions during downtime, a shadow ledger initialized via `OVERRIDE_INIT_0X9A` must be used. Once the core system recovers, all shadow entries undergo asynchronous reconciliation against the primary GL.
