# COM-111: T+2 Settlement Adjustments for Unplanned Public Holidays

<a id="COM-111-D01"></a>
## 1. Unplanned Holiday Declarations
When the government announces an unplanned public holiday, Ngân hàng Mô phỏng must immediately execute the `HOLIDAY_INJECT` script. This modifies the core system's calendar, shifting all scheduled T+2 settlements forward by the duration of the holiday.

<a id="COM-111-D02"></a>
## 2. Paygate Forward-Dating
Paygate processing modules will automatically forward-date any recurring automated transfers scheduled during the unplanned holiday. If a transfer was initiated on the eve of the holiday, its effective Value Date is locked to the next valid working day to prevent premature debiting.
