# COM-104: EOD Batch Processing Failures and Rollback Mechanisms

<a id="COM-104-D01"></a>
## 1. Batch Abort Conditions
The End-of-Day (EOD) batch at Ngân hàng Mô phỏng will automatically abort if the reconciliation variance exceeds the `VAR_TOLERANCE_MAX` threshold. This is often caused by unresolved asynchronous Paygate acknowledgments.

<a id="COM-104-D02"></a>
## 2. Rollback Execution
When an abort occurs, the system initiates a staggered rollback. Any late fees processed during the failed batch are queued in the `REVERSAL_QUEUE_PENDING` table. A manual override flag must be set by IT Ops to resume the corrected batch processing.
