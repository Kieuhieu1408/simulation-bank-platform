# COM-114: Automated Clearing House (ACH) Holiday Queuing Rules

<a id="COM-114-D01"></a>
## 1. ACH Inbound Queuing
During declared holidays at Ngân hàng Mô phỏng, the ACH gateway remains active but operates in a queuing-only mode. Inbound files are decrypted, validated for syntax, and parked in the `ACH_HOLIDAY_HOLD` directory. No GL postings occur.

<a id="COM-114-D02"></a>
## 2. Day-1 Processing Surge
On the first business day following a holiday, the Paygate system prioritizes the `ACH_HOLIDAY_HOLD` queue before accepting new real-time intra-day transfers. To manage the Day-1 surge, concurrent processing threads are temporarily doubled, and SLA alerts for real-time transfers are muted for the first 2 hours of operation.
