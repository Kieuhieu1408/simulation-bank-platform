# COM-109: Manual Intervention for Suspended Cross-Border Paygate Messages

<a id="COM-109-D01"></a>
## 1. SWIFT to Paygate Translation Failures
When SWIFT MT103/MT202 messages fail to translate cleanly into local Paygate JSON payloads due to character encoding glitches, they are suspended in the `CROSS_BORDER_EXCEPTIONS` queue at Ngân hàng Mô phỏng.

<a id="COM-109-D02"></a>
## 2. Maker-Checker Override
Resolving translation failures requires a strict Maker-Checker manual override. The Maker manually edits the parsed XML/JSON payload to correct encoding errors, and the Checker verifies the beneficiary details against the original SWIFT raw text before releasing the message.
