# COM-102: Emergency GL Reconciliation During Unplanned Core Downtime

<a id="COM-102-D01"></a>
## 1. Unplanned Outage Declarations
If Ngân hàng Mô phỏng experiences an unexpected loss of core database quorum (Event Code: QRM_LOSS_7), the incident response team immediately isolates the inter-bank Paygate node to prevent cascading message duplication.

<a id="COM-102-D02"></a>
## 2. GL Force-Balancing
To re-establish balance consistency, the GL must be force-balanced using the last known snapshot (LKS). Delta transactions queued in the Paygate local datastore are replayed sequentially using idempotent keys to avoid double-crediting accounts.
