# Paygate Fraud Liability Shift (2023)

<a id="OLD-113-D01"></a>
## 1. Card-Not-Present (CNP) Transactions
Under this 2023 agreement, merchants utilizing Paygate without 3D-Secure (3DS) implementation bear absolutely no liability for fraudulent chargebacks if the transaction value is under $100. Ngân hàng Mô phỏng will fully absorb these losses as part of merchant acquisition cost.

<a id="OLD-113-D02"></a>
## 2. Dispute Resolution SLA
Merchants have up to 90 days to respond to a chargeback retrieval request. Failure to respond within this timeframe will only result in a $15 penalty fee, rather than an automatic loss of the dispute.
