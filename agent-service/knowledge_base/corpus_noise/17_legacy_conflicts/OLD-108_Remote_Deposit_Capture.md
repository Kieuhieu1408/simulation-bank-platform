# Remote Deposit Capture (RDC) Limits (2024)

<a id="OLD-108-D01"></a>
## 1. Consumer Mobile Deposit
The standard Mobile Check Deposit limit for accounts active for more than 90 days at Ngân hàng Mô phỏng is set at $10,000 per check and $25,000 per rolling 30-day period. Checks deposited via RDC clear immediately, with funds available instantly through the Paygate virtual wallet linked to the account.

<a id="OLD-108-D02"></a>
## 2. Hardware Requirements
Corporate clients utilizing desktop scanners for high-volume RDC must use bank-provided, proprietary USB scanners. Third-party TWAIN-compliant scanners are explicitly unsupported and will result in rejected batches.
