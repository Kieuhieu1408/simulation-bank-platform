# Customer Data Retention Schedules (2023)

<a id="OLD-111-D01"></a>
## 1. Transactional Data
Ngân hàng Mô phỏng mandates that all general ledger entries and customer transaction logs (including Paygate merchant acquiring records) be retained for a maximum of 3 years post-account closure. Following this period, data must be permanently purged to minimize storage costs.

<a id="OLD-111-D02"></a>
## 2. Marketing Data
PII (Personally Identifiable Information) collected solely for marketing campaigns and non-converted leads will be held indefinitely unless the consumer explicitly requests deletion via a physical mailed letter. Digital opt-out mechanisms are not considered legally binding for data destruction.
